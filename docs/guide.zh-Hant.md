# 菜本易使用說明

[English](guide.md)

菜本易計算食譜成本、每份成本、每個餐牌項目的食材成本率（food cost %）及建議售價。所有
計算都在你的瀏覽器內進行，不會上載任何資料。

> **只供估算，並非會計或稅務意見。**結果完全取決於你輸入的價錢、可用率及用量。菜本易不計算
> 營養或致敏原。

## 1. 開啟菜本易

- **網上版：**開啟已發佈的網站（見 README）。首次開啟後亦可離線使用。
- **在自己電腦執行**（需要 Node.js 22 或以上）：

```sh
npm ci
npm start   # 建立網站並在 http://127.0.0.1:4893/ 提供
```

- **Docker：**見 README。容器只提供靜態網站。

第一次開啟時會載入**茶餐廳示範**，方便你參考。「資料及設定 → 新的空白項目」可由零開始。

## 2. 食材

輸入每包（每件）的入貨資料：包裝數量、單位及價錢，例如梅頭肉每斤 $62、410 克淡奶每罐
$11.50、雞蛋 30 隻 $48。

- **可用率 %**：修剪、去皮或起骨後剩下的比例（例如梅頭肉 88%）。實際成本會相應提高：
  每斤可用肉 $62 ÷ 0.88。
- **密度（克／毫升）**：只在「以重量買、以容量用」（或相反）時需要，例如以毫升買、以克用的生抽。
- **每件克數**：只在以件計而買入單位是重量（或相反）時需要。
- **實際成本**顯示每公斤、每公升或每件的可用成本。

數字可用全形輸入（１２．５）及千位逗號（1,250）。份量（不包括價錢）亦可輸入分數：`1/2`、
`1 1/2`、`½` 或 `1½`。

**價錢紀錄：**修改價錢或包裝時，舊價錢、包裝及日期會保留（最多 50 個）。包裝相同時，食材會顯示
變幅，例如「↑ 12.9%（自 2026-09-01）」。舊價錢列在「加價影響」頁。

可用「匯入 CSV」批量輸入。第一行為欄位名稱，英文或中文均可：`名稱, 包裝數量, 單位, 價錢,
可用率 %, 密度 g/ml, 每件重量 g, 價格日期, 備註`。單位可寫 `斤`、`兩`、`kg`、`g`、`lb`、
`oz`、`ml`、`L`、`杯`、`湯匙`、`茶匙`、`件` 等。有問題的行會連同行號列出而不匯入，其餘照常匯入。

## 3. 食譜及子食譜

食譜要寫明**產出**（例如 12 份、1 公升或 350 克）及材料。每一行可以是食材，亦可以是**另一個
食譜**（醬汁、糖水、麵糰），所以叉燒飯可以用叉燒，叉燒用叉燒醬，叉燒醬又用糖水。

- 每行的**損耗 %** 是該行額外的損失（倒瀉、黏鍋）。損耗 10% 即需要 1 ÷ 0.9 倍份量。
- 每行顯示**成本**及佔整個食譜的**佔比**。子食譜行下的「展開」可查看該子食譜。
- **按比例調整**顯示改為另一個份量時每項材料的份量及成本。
- **手上材料可以做多少？**計算某食材的數量足夠製作多少（包括經子食譜使用）。

- 每行的**計成本 %** 是該行成本計入多少（預設 100%）。一撮鹽或少量葱可設為 0%（少量）：該行
  毋須換算單位，報表會註明「少量，不計成本」。
- **複製食譜**會複製一份，方便做變化版本。
- **材料總重**把每行按輸入的份量換算成克再相加（未計損耗）；食譜以份數計產出時亦顯示每份重量。
  以容量或件數計的行需要密度或每件克數，否則會列出。
- **人工及雜費（可選）：**每批人工分鐘 × 每小時成本，加每批固定雜費及／或食材成本的百分比。
  菜本易會顯示每批及每單位產出的**全部成本**。例如 45 分鐘、每小時 $72，人工是 $54；食材成本
  $200，固定雜費 $10 加 10% 雜費，全部成本為 $200 + $54 + $30 = $284。餐牌上的 food cost %
  不包括這些。

如果食譜互相引用成循環（A 用 B、B 又用 A），菜本易會列出整個循環並拒絕給出數字。子食譜最多
可嵌套 20 層。

### 計算示例

以下取自 `examples/cha-chaan-teng.json`（`saucepenny cost --lang zh-HK`）：

<!-- doc-test: cost examples/cha-chaan-teng.json --lang zh-HK -->

```text
叉燒 Char siu (產出 12 份)
  梅頭肉 Pork shoulder  3 斤  211.36  94.3%
  ↳ 叉燒醬 Char siu glaze  250 毫升 (+10.0% 損耗)  12.66  5.7%
  總成本 224.03 · 每份 18.67
```

梅頭肉一行：3 斤 × $62 ÷ 0.88 可用率 = $211.36。叉燒醬一行：叉燒醬每 500 毫升 $22.79，
用 250 毫升、損耗 10%：250 × 22.79… ÷ 500 ÷ 0.9 = $12.66。每份 = $224.03 ÷ 12 = $18.67。

## 4. 餐牌

每個餐牌項目使用一個食譜及其份量（例如 1 份、加料 0.5 份，或湯 250 毫升）。

- **食材成本率** = 每份成本 ÷ 不含服務費的售價。如售價已包括一成服務費，菜本易會先扣除
  （售價 ÷ 1.1）。
- **顏色分級：**30% 或以下為良好，高於 35% 為偏高，中間為留意（兩個界線可在「資料及設定」更改）。
  分級一律同時以文字顯示。
- **建議售價** = 每份成本 ÷ 目標成本率，如售價包括服務費則再加上服務費，然後**向上**進位至仙、
  一毫、五毫、一元或「尾數 8」（41.2 → 48）。由於只會向上進位，按建議售價計的實際成本率（顯示在
  旁）永遠不會高於目標。
- **毛利** = 不含服務費的售價 − 每份成本。

<!-- doc-test: cost examples/cha-chaan-teng.json --lang zh-HK -->

```text
叉燒飯 Char siu rice (叉燒飯 Char siu rice, 1 份)
  售價 52.00 · 成本 23.54
  食材成本率 45.3% (偏高) · 毛利 28.46
  目標 32.0% → 建議售價 78.00 (按建議售價 30.2%)
```

### 餐牌分析（v0.3）

餐牌表下面的「餐牌分析」按受歡迎程度及毛利把菜式分類。輸入某段時間每項售出多少份，或按
「匯入銷售 CSV」匯入有兩欄的檔案：`項目`（餐牌項目名稱）及`售出`（英文欄名 `item`、`sold`
亦可；重複的項目會相加，不認識的名稱或錯誤數字會按行列出）。「下載銷售表」會給你一個已列出
所有餐牌項目的檔案。

- **毛利** = 不含服務費的售價 − 每份成本。
- **銷售佔比** = 售出 ÷ 總售出。佔比達平均佔比的 70% 或以上算**受歡迎**（4 項時：0.7 ÷ 4 =
  17.5%）。
- 毛利達按銷量加權的平均毛利或以上算**毛利高**。
- 分類：**主力**（受歡迎、毛利高）、**提高毛利**（受歡迎、毛利低）、**多推廣**（毛利高、較少人點）、
  **檢討**（毛利低、較少人點）。沒有售價或未有核對成本的項目不計入，並會列出。

以示例項目計，售出叉燒飯 320、奶茶 540、凍檸茶 150、加叉燒 40（共 1,050 份），加權平均毛利為
19.15，佔比達 17.5% 算受歡迎：叉燒飯（30.5%，毛利 28.46）是**主力**，奶茶（51.4%，14.68）
是**提高毛利**，凍檸茶（14.3%，15.54）及加叉燒（3.8%，18.67）是**檢討**。「匯出分析（CSV）」
可儲存此表。銷售份數不會存入項目。

## 5. 加價影響

### 供應商價目表（v0.3）

「用供應商價目表更新價錢」讀取有名稱、包裝數量、單位及價錢欄的 CSV（價格日期可有可無；供應商
編號等其他欄會略過）。每行會按相同名稱，或按你以前在這部裝置選過的配對，對應到你的食材；未配對
的行請自行選擇食材。表中列出現價、新價及**每單位**變幅（例如 13 / 1 kg → 28 / 2 kg 即每單位
+7.7%）。價錢相同的行不會預先勾選。按「套用」之前不會改動任何資料；舊價錢會保留在各食材的價格
紀錄。

「加價影響」顯示某食材每包價錢改變後的結果：所有成本會改變的食譜及餐牌項目都會列出之前、之後
及差額，包括只經子食譜使用該食材的項目。下面的「這種食材以前的價錢」列出保留的舊價錢；按
「用這個價錢試算」即可從該價錢開始計算。

<!-- doc-test: impact examples/cha-chaan-teng.json pork-shoulder 70 --lang zh-HK -->

```text
食譜 · 叉燒 Char siu: 224.03 → 251.30 (+27.27)
餐牌項目 · 加叉燒 Extra char siu: 9.33 → 10.47 (+1.14)
```

## 6. 檔案、列印及私隱

- 「儲存項目（.json）」及「開啟項目（.json）」用於在裝置之間搬移項目，亦是你的備份。
  「餐牌成本」及「食譜成本」匯出 CSV 供試算表使用；可能被試算表當作公式執行的儲存格會加上 `'`。
- 「列印成本卡」列印餐牌表及每個食譜的成本卡。
- 項目只儲存在這個瀏覽器（IndexedDB）。「刪除這部裝置上的所有資料」會刪除項目及設定。
- 「資料」頁的「這部裝置上的儲存」顯示瀏覽器是否同意在空間不足時仍保留資料；「再向瀏覽器申請」
  會再次申請。瀏覽器仍可能清除網站資料，所以請保留備份檔。
- 如果 20 次修改或 14 日都未儲存備份，會出現提醒，提供「儲存備份（.json）」；按「稍後」會隱藏
  7 日。提醒從不使用網絡。
- **自訂量度**（「資料」頁）：新增自己的量度，例如一殼 = 40 克或一碗 = 300 毫升，即可在食譜行
  使用。使用中的量度不能刪除。

## 7. 命令列

同一個計算引擎亦可在命令列使用（需要 Node.js 22 或以上）：

```sh
npm run saucepenny -- cost examples/cha-chaan-teng.json --lang zh-HK
npm run saucepenny -- check examples/social-enterprise-lunch.json --lang zh-HK
npm run saucepenny -- impact examples/cha-chaan-teng.json sugar 15 --lang zh-HK
```

結束碼：0 所有數字已核實；1 用法或檔案錯誤；2 部分項目有問題（每項均有說明）；4 內部核對失敗
（請回報）。

## 8. 數字如何核對

菜本易內部所有數值都是精確分數，只在顯示時才四捨五入。另有獨立檢查器以不同方法（先把每道菜
展開成原材料包數）重算每個食譜總成本、每行成本、每份成本、食材成本率及建議售價，兩者完全相同
才會顯示。完整規則見 [calculation-rules.md](calculation-rules.md)；單位常數及法例出處見
[units.md](units.md)。
